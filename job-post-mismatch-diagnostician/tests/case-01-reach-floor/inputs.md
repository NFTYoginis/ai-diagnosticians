# Case 01 — inputs

Constructed case. Paste everything below into a project running the diagnostician, then say
"Diagnose this requisition."

---

## The requisition

- **QA Automation Engineer**, mid-level
- Fully remote within one country
- Posted range **$92,000 – $104,000**
- **38 days open.** No edits of any kind: no title change, no requirement change, no band change,
  no channel change, no sponsorship change
- Running on three channels: Board A, Board B, and the company careers page

### The post

Title: **"QA Automation Engineer"**

Requirement block, 9 items, required and preferred separated:

*Required* — 3+ years in test automation · one of Playwright, Cypress, or Selenium · CI pipeline
experience · a scripting language · comfortable owning a regression suite

*Preferred* — API contract testing · performance testing · a mobile automation framework · prior
experience in a regulated environment

Work model stated explicitly in the first line of the body: fully remote within the country, no
office attendance required.
